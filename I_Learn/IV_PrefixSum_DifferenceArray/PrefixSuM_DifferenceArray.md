# Day 4 前缀和与差分（Prefix Sum & Difference Array）

> 学习路线：Day 1 二分查找 → Day 2 双指针 → Day 3 滑动窗口 → **Day 4 前缀和与差分** → Day 5 单调栈与单调队列
> 一句话定位：**前缀和 = 用 O(1) 回答"区间求和"；差分 = 用 O(1) 完成"区间修改"**。两者互为逆运算，是后续树状数组、线段树、DP 优化的地基。
> 前置衔接：Day 3 的滑动窗口靠"增量维护窗口状态"把 O(n²) 压成 O(n)，但它要求窗口**只能右扩左缩**。今天的前缀和则从另一个角度砍掉区间求和的开销，且**不要求任何单调性**。

## 〇、先来一个最小例子（建立直觉）

**问题**：数组 `a = [2, 1, 5, 1, 3, 2]`（下标 0~5）。回答两个问题：

1. 区间 `[1, 4]`（即 1+5+1+3）的和是多少？
2. 区间 `[2, 3]`（即 5+1）的和是多少？

**暴力做法**：每个问题都从头遍历一遍 → 每次 O(n)，问 q 次就是 **O(n·q)**。

**优化做法**：提前算好"从开头到每个位置的总和"，存成一张表：

| i | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| `pre[i]` 含义 | 前 0 个数之和 | 前 1 个数之和 | … | | | | 前 6 个数之和 |
| `pre[i]` 值 | **0** | 2 | 3 | 8 | 9 | 12 | **14** |

于是：

- 区间 `[1,4]` 的和 = `pre[5] - pre[1]` = 12 − 2 = **10** ✅
- 区间 `[2,3]` 的和 = `pre[4] - pre[2]` = 9 − 3 = **6** ✅

**关键发现**：一次 O(n) 预处理之后，**任何区间求和都只是一次减法，O(1)**。这张表就叫**前缀和数组**。

<details>
<summary>最小例子的 Python 实现</summary>

```python
def build_prefix(a: list[int]) -> list[int]:
    pre = [0] * (len(a) + 1)          # pre 长度 n+1，pre[0] = 0 是"哨兵"
    for i, v in enumerate(a):
        pre[i + 1] = pre[i] + v
    return pre

def range_sum(pre: list[int], l: int, r: int) -> int:
    """闭区间 [l, r] 的元素和"""
    return pre[r + 1] - pre[l]

a = [2, 1, 5, 1, 3, 2]
pre = build_prefix(a)
print(range_sum(pre, 1, 4))   # 10
print(range_sum(pre, 2, 3))   # 6
```

</details>

## 一、算法核心思想

### 1.1 前缀和（Prefix Sum）

**定义**：对原数组 `a[0..n-1]`，构造 `pre[0..n]`（长度 n+1），其中

```
pre[0] = 0
pre[i] = a[0] + a[1] + ... + a[i-1]      （前 i 个元素之和）
```

**核心公式（务必背下）**：

```
sum(a[l..r]) = pre[r+1] - pre[l]          // 闭区间 [l, r]
```

**为什么成立**：`pre[r+1]` 比 `pre[l]` 多出来的，恰好是 `a[l..r]` 这一段。

**本质**：一种**空间换时间**的预处理——把"重复计算的区间求和"提前摊平到一张表里。它的威力在**多次查询**时才会爆发。

### 1.2 差分数组（Difference Array）

**定义**：差分是前缀和的**逆运算**。对 `a[0..n-1]`，定义 `diff[0..n]`（长度 n+1）：

```
diff[0] = a[0]
diff[i] = a[i] - a[i-1]     (i >= 1)
```

**核心操作**：要把原数组的**整个区间 `[l, r]` 都加上 v**，只需两步 O(1)：

```
diff[l]   += v
diff[r+1] -= v
```

完成后，对 `diff` 求一次前缀和即可**还原**出最终数组。

**为什么成立**：对 diff 求前缀和时，`diff[l]` 处的 `+v` 会被累计到 `a[l]` 及之后的所有位置；而 `diff[r+1]` 处的 `−v` 从 `a[r+1]` 开始把这笔增量抵消掉。净效果就是**只有 `[l, r]` 被加了 v**。

**二者的对偶关系**（非常重要）：

```
a  ──(求差分)──▶  d  ──(求前缀和)──▶  a     // 一来一回，数组复原
d  ──(求前缀和)─▶  a  ──(求差分)────▶  d
```

> 记忆法：**前缀和 = 区间查询神器；差分 = 区间修改神器。** 一个管"查"，一个管"改"。

### 1.3 能力对照表（什么时候用谁）

| 需求 | 暴力 | 前缀和 | 差分数组 | 线段树 / 树状数组 |
|------|------|--------|----------|-------------------|
| 区间求和（单次/多次） | O(n) | ✅ **O(1)** | O(n) | O(log n) |
| 区间整体加减（多次） | O(n) | ❌ O(n)（需重建） | ✅ **O(1)** | O(log n) |
| 既有修改又有查询（交替） | O(n) | ❌ 不适用 | ❌ 不适用 | ✅ O(log n) |

**选型口诀**：

- **只查不改** → 前缀和（LC303 / LC560 / LC974）
- **只改，最后统一看结果**（离线批量修改）→ 差分（LC1109 / LC1094）
- **边改边查（在线）** → 树状数组 / 线段树（进阶内容，后续安排）

### 1.4 二维前缀和（矩阵版）

定义 `pre[i][j]` = 以 `(0,0)` 为左上、`(i-1, j-1)` 为右下的子矩阵元素和。

**构造公式（容斥）**：

```
pre[i][j] = pre[i-1][j] + pre[i][j-1] - pre[i-1][j-1] + matrix[i-1][j-1]
```

**查询公式（求子矩阵 `(r1,c1)` 到 `(r2,c2)` 的和）**：

```
sum = pre[r2+1][c2+1] - pre[r1][c2+1] - pre[r2+1][c1] + pre[r1][c1]
```

四个角"加、减、减、加"——画个图就能自己推出来，不必死记。

## 二、复杂度分析与原因推导

### 一维前缀和

| 阶段 | 复杂度 | 推导依据 |
|------|--------|----------|
| 预处理 | **O(n) 时间 / O(n) 空间** | 循环 n 次，每次 O(1) 递推 `pre[i+1] = pre[i] + a[i]` |
| 单次区间查询 | **O(1)** | 只做一次减法 |
| q 次查询总计 | **O(n + q)** | 预处理 n + 查询 q×O(1) |

**对比**：暴力做法是 O(n·q)。当 n = 10⁵、q = 10⁵ 时，从 10¹⁰ 次运算降到 2×10⁵ —— 这就是从"跑不完"到"毫秒级"的差别。

### 一维差分

| 阶段 | 复杂度 | 推导依据 |
|------|--------|----------|
| m 次区间修改 | **O(m)** | 每次只动 `diff` 的两个端点，与区间长度完全无关 |
| 还原数组 | **O(n)** | 对 diff 求一次前缀和 |
| 总计 | **O(n + m)** 时间 / **O(n)** 空间 | |

**对比**：暴力修改 m 次区间，每次 O(区间长度) ≈ O(n)，总计 O(n·m)。差分把它切成"m 次 O(1) 打标记 + 1 次 O(n) 统一结算"。

### 二维前缀和

- 预处理 **O(m·n)**（遍历整个矩阵，每格 O(1)）
- 单次子矩阵查询 **O(1)**（4 次数组访问）
- 空间 **O(m·n)**
- ` 一维前缀和：代表一条线段的总和（从起点到当前点）。二维前缀和：代表一个矩形面积的总和（从左上角 (0,0) 到当前坐标 (i,j) 这个大框里所有元素的和）。`

### 前缀和 + 哈希表（LC560 型）

把"求有多少个子数组和为 k"从 O(n²) 降到 **O(n)**：

- 暴力：枚举所有 (i, j) 共 O(n²) 对，每对再求和 O(n)（或 O(1) 若配合前缀和）→ 最优也要 **O(n²)**。
- 优化：子数组和 `sum(i..j) = pre[j+1] - pre[i]`，令其等于 k，即 `pre[i] == pre[j+1] - k`。
  枚举右端点时，用哈希表 O(1) 查出"之前出现过多少个 `pre[j+1] - k`" → **总 O(n)**。
- 空间 **O(n)**（哈希表最多存 n+1 个不同的前缀和值）。

## 三、核心模板与边界细节

### 3.1 一维前缀和模板（强烈推荐 1-indexed 写法）

```python
# 构造
pre = [0] * (n + 1)
for i in range(n):
    pre[i + 1] = pre[i] + a[i]

# 查询闭区间 [l, r]
s = pre[r + 1] - pre[l]
```

**循环不变量**：`pre[i]` 恒等于 `a[0..i-1]` 的和。构造循环中每次进入第 i 轮时该性质成立，故结束时全部成立。

**为什么用 1-indexed（长度 n+1）**：`pre[0] = 0` 是一个**哨兵**，它让"从 0 开始的区间"也能用同一个公式 `pre[r+1] - pre[l]` 处理，彻底消灭 `if l == 0` 的特判。这是本算法最重要的工程技巧。

### 3.2 一维差分模板

```python
diff = [0] * (n + 2)              # 多开 1~2 格，防 r+1 越界
for l, r, v in operations:        # 区间 [l, r] 加 v
    diff[l]     += v
    diff[r + 1] -= v

# 还原（对 diff 求前缀和）
cur = 0
for i in range(n):
    cur += diff[i]
    a[i] = cur
```

⚠️ **注意**：若题目给的是**1-based 下标**（例如 LC1109 的航班编号从 1 到 n），`diff` 要开到 `n+2`，还原时从第 1 位开始遍历（见例题 3）。这是差分题最常见的 WA 点。

### 3.3 前缀和 + 哈希模板（统计型）

```python
cnt = {0: 1}        # 必须初始化！空前缀和为 0，出现过 1 次
pre, ans = 0, 0
for v in nums:
    pre += v
    ans += cnt.get(pre - k, 0)     # 先查询，后插入（避免把自身算进去）
    cnt[pre] = cnt.get(pre, 0) + 1
```

### 3.4 易错点清单（按踩坑频率排序）

| # | 易错点 | 症状 | 正确做法 |
|---|--------|------|----------|
| 1 | **下标错位** | 差一位，结果总差一个元素 | 统一用 `pre[i+1] = pre[i] + a[i]`，区间和 = `pre[r+1] - pre[l]` |
| 2 | **差分 `r+1` 越界** | panic / IndexError | `diff` 开 `n+2` 长度 |
| 3 | 1-based 输入未换算 | 整体偏移一位 | 还原时从第 1 位循环到 n，输出 `ans[i-1]` |
| 4 | 哈希表忘记初始化 `{0:1}` | 漏统计"从下标 0 开始"的子数组 | 必须写 `cnt = {0: 1}` |
| 5 | **先插入后查询** | 把 v=0 的空子数组也算进去，答案偏大 | 顺序固定：**先 `ans += cnt[pre-k]`，再 `cnt[pre]++`** |
| 6 | 取模负数 | Go 中 `-1 % 5 = -1`，导致哈希统计错误 | Go 用 `((x % k) + k) % k`；Python 的 `%` 已保证非负 |
| 7 | 整数溢出 | 大数求和爆 int32 | Go 用 `int64`；Python 无此问题 |
| 8 | 二维容斥漏项 | 子矩阵和总是偏大/偏小 | 记住"四角 +− −+"的对称结构 |

## 四、经典实战例题

### 例题 1｜LeetCode 303. 区域和检索 - 数组不可变（前缀和入门必做题）

**题目**：给定整数数组 `nums`，实现 `NumArray` 类，支持 `sumRange(left, right)` 返回下标 `left` 到 `right`（**闭区间**）的元素和。

**样例**：

```
输入：["NumArray","sumRange","sumRange","sumRange"]
     [[[-2,0,3,-5,2,-1]],[0,2],[2,5],[0,5]]
输出：[null, 1, -1, -3]
```

**思路**：`nums` 不可变 → 典型的"**一次预处理，多次查询**"。构造时算出 `pre`；查询时直接 `pre[right+1] - pre[left]`。

---

### 例题 2｜LeetCode 560. 和为 K 的子数组（前缀和 + 哈希）

**题目**：给定整数数组 `nums` 和整数 `k`，统计**和为 k 的连续子数组**的个数。

**样例**：

- `nums = [1,1,1], k = 2` → 输出 `2`（`[1,1]` 出现两次）
- `nums = [1,2,3], k = 3` → 输出 `2`（`[1,2]` 和 `[3]`）
- `nums = [-1,-1,1], k = 0` → 输出 `1`（`[-1,1]`）

**思路**：设 `pre[j+1] = pre[i] + sum(i..j)`。要 `sum(i..j) = k`，即需要 `pre[i] = pre[j+1] - k`。
从左到右扫描，用哈希表记录**此前每个前缀和值出现的次数**；每到一个新位置，查 `cnt[pre - k]` 并累加即可。

> ⚠️ 这题**不能**用滑动窗口——`nums` 含负数，窗口和不再具有单调性，右移左指针可能反而让和变大。这正是前缀和相对 Day 3 滑动窗口的优势所在。

---

### 例题 3｜LeetCode 1109. 航班预订统计（差分入门必做题）

**题目**：有 `n` 个航班，编号 **1 到 n**。给定 `bookings[i] = [first_i, last_i, seats_i]`，表示从 `first_i` 到 `last_i`（**闭区间，1-based**）的每个航班都预订了 `seats_i` 个座位。返回每个航班的预订总数。

**样例**：

- `bookings = [[1,2,10],[2,3,20],[2,5,25]], n = 5` → 输出 `[10,55,45,25,25]`

**思路**：这是"**多次区间加法 + 最后一次统一看结果**"的教科书场景。用差分数组，每条预订只改两个端点，最后求前缀和还原。

### 例题 4｜LeetCode 304. 二维区域和检索 - 矩阵不可变（二维前缀和）

**题目**：给定二维矩阵，实现 `NumMatrix` 类，支持 `sumRegion(row1, col1, row2, col2)` 返回子矩阵元素和。

class NumArray:
    def __init__(self, nums: list[int]):
        self.pre = [0] * (len(nums) + 1)

            self.pre[i + 1] = self.pre[i] + v

### 例题 2：LC560 和为 K 的子数组

<details>
<summary>Python 实现</summary>

```python
def subarray_sum(nums: list[int], k: int) -> int:
    cnt = {0: 1}          # 空前缀和，处理"从下标 0 开始"的子数组
    pre = ans = 0
    for v in nums:
        pre += v
        ans += cnt.get(pre - k, 0)      # 先查询
        cnt[pre] = cnt.get(pre, 0) + 1  # 后插入
    return ans
```

</details>

**执行过程演示**（`nums = [1,1,1], k = 2`）：

| i | v | pre | 查 `pre-k` | `cnt.get(pre-k)` | ans | 插入后 cnt |
|---|---|-----|-----------|------------------|-----|-----------|
| 初始 | — | 0 | — | — | 0 | {0:1} |
| 0 | 1 | 1 | −1 | 0 | 0 | {0:1, 1:1} |
| 1 | 1 | 2 | 0 | 1 | 1 | {0:1, 1:1, 2:1} |
| 2 | 1 | 3 | 1 | 1 | **2** | {0:1, 1:1, 2:1, 3:1} |

def corp_flight_bookings(bookings: list[list[int]], n: int) -> list[int]:
    diff = [0] * (n + 2)
    for l, r, seats in bookings:
        diff[l] += seats
        diff[r + 1] -= seats
    ans, cur = [], 0
    for i in range(1, n + 1):      # 1-based，从 1 遍历到 n
        cur += diff[i]
        ans.append(cur)
    return ans

### 例题 4：LC304 二维区域和检索

<details>
<summary>Python 实现</summary>

```python
class NumMatrix:
    def __init__(self, matrix: list[list[int]]):
        m, n = len(matrix), len(matrix[0]) if matrix else 0
        self.pre = [[0] * (n + 1) for _ in range(m + 1)]
        for i in range(1, m + 1):
            for j in range(1, n + 1):
                self.pre[i][j] = (self.pre[i - 1][j] + self.pre[i][j - 1]
                                  - self.pre[i - 1][j - 1] + matrix[i - 1][j - 1])

    def sum_region(self, r1: int, c1: int, r2: int, c2: int) -> int:
        p = self.pre
        return p[r2 + 1][c2 + 1] - p[r1][c2 + 1] - p[r2 + 1][c1] + p[r1][c1]
```

</details>

## 六、课后进阶思考与方法延伸

### 思考题 1｜LeetCode 974. 和可被 K 整除的子数组（推荐先做）

**题意**：统计和**能被 k 整除**的连续子数组个数。

**提示**：沿用 LC560 的框架，但把"前缀和相等"换成"**前缀和模 k 同余**"——由同余定理，`sum(i..j) ≡ 0 (mod k)` ⟺ `pre[j+1] % k == pre[i] % k`。因此哈希表存的是**前缀和模 k 的余数**的出现次数。

<details>
<summary>参考实现（Python）</summary>


```python
def subarrays_div_by_k(nums: list[int], k: int) -> int:
    cnt, pre, ans = {0: 1}, 0, 0
    for v in nums:
        pre = (pre + v) % k        # Python 的 % 已保证结果非负
        ans += cnt.get(pre, 0)
        cnt[pre] = cnt.get(pre, 0) + 1
    return ans
```

样例：`nums = [4,5,0,-2,-3,1], k = 5` → 输出 `7`。

</details>

### 思考题 2｜LeetCode 1094. 拼车（差分的经典应用）

**题意**：`trips[i] = [num_i, from_i, to_i]` 表示有 `num_i` 名乘客从 `from_i` 上车、在 `to_i` **下车**。判断车（容量 `capacity`）能否在不超载的前提下接完所有乘客。

**提示**：每条行程就是对区间 `[from_i, to_i-1]` 加 `num_i`——注意**下车点不占座**，所以直接写 `diff[from] += num; diff[to] -= num` 即可（终点是开区间语义）。最后扫描一遍，任一时刻累计人数超过容量就返回 `false`。

<details>
<summary>参考实现（Python）</summary>

```python
def car_pooling(trips: list[list[int]], capacity: int) -> bool:
    diff = [0] * 1002
    for num, frm, to in trips:
        diff[frm] += num
        diff[to] -= num
    cur = 0
    for i in range(1001):
        cur += diff[i]
        if cur > capacity:
            return False
    return True
```

样例：`[[2,1,5],[3,3,7]], capacity=4` → `false`；`capacity=5` → `true`。

</details>

### 方法延伸

1. **前缀积 / 后缀积**：把"+"换成"×"就是同一套思想，见 **LeetCode 238. 除自身以外数组的乘积**（不用除法，两次遍历分别累乘左侧积与右侧积）。
2. **前缀和 + 单调性**：**当数组元素全为非负数时**，前缀和数组严格单调不减，可以对它**二分查找**——这恰好复用 Day 1 的二分能力。而**含负数时**前缀和失去单调性，就需要 Day 5 的**单调队列**来解"和 ≥ K 的最短子数组"（LC862）。
3. **二维差分**：一维差分的矩阵推广，用于"批量给子矩阵加值"（如 LC2132、LC2536），公式同样是四角 `+− −+`，只是作用在 diff 上。
4. **前缀和 × 哈希表**是一个通用降维套路：只要题目出现"**子数组的和满足某条件**"，第一时间联想 `(pre[j] - pre[i])` 与哈希计数。

### 衔接 Day 5

今天我们看到，**滑动窗口在含负数时会失效**（因为窗口和失去单调性，无法决定该收缩左端还是右端）。明天要学的 **Day 5 单调栈与单调队列**，正是用"维护一个单调结构"来恢复这种决策能力——它能在 O(n) 内解决"滑动窗口最大值"（LC239）和"和至少为 K 的最短子数组"（LC862，前缀和 + 单调队列）。可以说：**Day 4 给了一把尺子（前缀和），Day 5 给了一套让这把尺子保持有序的工具。**

### 今日一句话总结

> **前缀和 = 提前记账，一次减法换 O(1) 查询；差分 = 端点打标，两次标记换 O(1) 修改。二者互为逆运算，共同构成"区间问题"的第一性解法。**
> 记住三个数字：`pre[0]=0`（哨兵）、`pre[r+1]-pre[l]`（查询）、`diff[l]+=v; diff[r+1]-=v`（修改）。
